## 🌟 Project Overview

This project explores employee data to investigate **AI adoption across industries, job roles, and employee characteristics**. Python data analysis libraries are used to inspect the dataset, explore patterns, and visualize information.

## 🎯 Objectives

- 🔍 Explore and understand the dataset.
- 🧹 Inspect data and prepare it for analysis.
- 📊 Examine employee characteristics and AI adoption levels.
- 📈 Create visualizations using Matplotlib.
- 💡 Identify useful patterns from the available data.

## 🛠️ Tech Stack

| Tool | Purpose |
|---|---|
| 🐍 Python | Programming |
| 🐼 Pandas | Data manipulation and analysis |
| 🔢 NumPy | Numerical operations |
| 📉 Matplotlib | Data visualization |
| 📓 Jupyter Notebook | Interactive analysis |

## ⚙️ How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/joshikaa150/pandas-data-analysis.git
```

**2. Open the project folder**

```bash
cd pandas-data-analysis
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `og_project.ipynb` and run the cells.

## 📌 Dataset

The project uses `ai_job_impact.csv`, containing employee-related attributes such as age, gender, education level, industry, job role, years of experience, and AI adoption level.
